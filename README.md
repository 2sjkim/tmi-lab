# TMI Lab · Yonsei University

**Translational Medical Intelligence Lab**

We focus on multiple aspects of biomedical imaging—from data acquisition to image reconstruction, enhancement, and quality assessment. Our research spans medical physics, computational imaging, and machine learning to advance imaging technologies for healthcare and broader scientific applications.
